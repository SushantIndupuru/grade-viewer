# Grade Viewer

Grade Viewer is no longer available.

On August 31, 2026, Edupoint Educational Systems asked that this independent project stop using their trademarks in marketing and stop connecting to their web services. The live site complies: sign-in is disabled, and the site no longer contacts their systems.

[gradeviewer.org](https://gradeviewer.org) explains the letter in full.

Use your school’s official portal for grades and school mail.

Feedback: [contact@gradeviewer.org](mailto:contact@gradeviewer.org).
